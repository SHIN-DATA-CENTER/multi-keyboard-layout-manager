# M3 手動テストの結果

`docs/design/m3-gui.md` の H.4 に定めた手動チェックリストの記録。

- 開発機: Windows 11 Home 25H2（build 26200）。キーボードごとモードで、内蔵 PS/2 は 7/2、Keychron は 4/0。
- ビルド: `m3/gui` の `1ad21e0` の release 版。`mklm.exe`、`mklm-cli.exe`、`mklm-helper.exe` のビルド ID は、いずれも `0.1.0+7b879442a82641a88a2278bb402575da` で一致している。
- テスト前の状態: `mklm-cli status --json --all` を `Desktop\MKLM-backup-20260927\m3-before.json` に保存した。

## 第 1 回: キーボードの設定を変えない項目（2026-09-28、合格）

ユーザーが実施し、「すべて問題ありませんでした」と報告した。この回で UAC が出たら「いいえ」を押す約束で行った。

| 分野 | 項目 | 結果 |
|---|---|---|
| 初回起動 | T-START-5（ウィザードが「手順 1 / 4」で開く。「後でセットアップする」で閉じ、設定から開き直せる） | 合格 |
| 起動 | T-START-1〜4（状態行と一覧が正しい。多重起動では 1 つ目が前面に出る。`--tray`、`--quit`） | 合格 |

| 言語 | T-LANG-1〜2（再起動なしで日本語と英語が切り替わる。英語の画面でも日本語の機器名が出る） | 合格 |
| 入力方式 | T-IME-1〜3 | 合格 |
| 特定と判定 | T-ID-1〜3、T-DETECT-1〜2 | 合格 |
| メイン画面 | T-MAIN-1〜4（抜き差しの反映、非表示と再表示、レシーバーのバッジ、フォーカスが保たれる） | 合格 |

任意の項目（T-THEME-4 のハイコントラスト、T-A11Y-4 の 200% 表示、T-TRAY-3）も、個別の問題の報告はなかった。
