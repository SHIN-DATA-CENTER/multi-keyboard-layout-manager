# MKLM v0.2.0

Windows 11 24H2 以降向け（x64 / ARM64）。v0.1.0 からはインストーラーで手動更新してください。

## 主な変更

- キーボードごとモードのまま、PC の標準配列を JIS / US に変更できます。既定では各機器の今の配列を維持し、選んだキーボードだけ新しい標準に追従させられます。CLI は `standard jis|us --follow <keyboard>`、下見は `--dry-run`。
- 起動 ID の判定、再起動待ち・取り消し後の表示を修正しました。表示のために履歴を書き換えません。
- 再起動後の確認を物理キーボード単位にまとめ、HID collection の一部が不一致・未報告の場合に全件成功と誤表示しないようにしました。
- RDP の説明と、接続先の物理キーボードを Raw Input で確認できない場合の表示を改善しました。接続元のキーボードを個別変換する機能は含みません。
- 署名付き更新情報とインストーラーのハッシュを検証する自動更新を追加しました。更新のインストールは利用者が操作したときに行います。

## 利用上の注意と検証範囲

標準配列を変更した後は、シャットダウンではなく必ず **再起動** してください。再起動前にサインアウト・ユーザー切り替え・シャットダウンをすると、パスワードを打つ配列が早めに変わる可能性があります。

この開発機で標準配列変更、配列維持、再起動後の確認・確定、取り消し、表示と打鍵を確認しました。追加の長い手動検証はメンテナーの判断で省略しました。再起動前の新しいサインイン、高速スタートアップ、スリープ・休止、未接続キーボードへの指定、RDP の追加条件、アクセシビリティ、および ARM64 Windows 11 での実機実行・起動 ID の確認は未検証です。コンパイル・自動テストと実機検証は区別しています。

問題が見つかった場合は [Issues](https://github.com/SHIN-DATA-CENTER/multi-keyboard-layout-manager/issues) に報告してください。パスワード・秘密鍵などは添付しないでください。

インストーラー本体の Windows コード署名はありません。SmartScreen 等の注意と、更新情報の署名を手で検証する方法は [インストールガイド](https://github.com/SHIN-DATA-CENTER/multi-keyboard-layout-manager/blob/v0.2.0/docs/install-guide.ja.md) を参照してください。
