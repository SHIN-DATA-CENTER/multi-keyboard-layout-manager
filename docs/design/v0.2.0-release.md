## リリースノート案

MKLM v0.2.0 では、キーボードごとモードのまま PC の標準配列を変更できます。既定では、標準に従うキーボードに今の配列を割り当て、再起動後も維持します。切り替えたいキーボードだけ GUI で選ぶか、CLI の `standard jis|us --follow <keyboard>` で指定できます。下見は `--dry-run` で確認できます。

起動 ID の判定と、再起動後の確認・取り消し状態の表示を修正しました。複数の HID collection は物理キーボード単位で確認し、一部の不一致や未報告を成功として表示しません。RDP のセッションから物理キーボードを確認できない場合の表示・説明も改善しました。RDP の接続元キーボードを個別に変換する機能は含みません。

自動更新機能は、署名付き更新情報とインストーラーのハッシュを検証し、利用者が更新操作を選んだときにインストールします。v0.1.0 からは v0.2.0 を手でインストールしてください。標準配列の変更には PC の再起動が必要です。変更後はサインアウトやシャットダウンを挟まず、再起動してください。

このリリースノートは公開前稿です。実機条件、署名、GitHub のビルド・インストーラーの検査、公開後の canary が完了してから公開結果を追記します。

ARM64 Windows 11 での実機実行・BootId の確認は未実施です。ARM64 のコンパイル検査とは区別してください。

この PC で標準配列変更と取り消しを再起動後まで確認しましたが、再起動前の新しいサインイン、高速スタートアップ、スリープ・休止、未接続キーボードへの指定、RDP の一部の条件などの追加手動検証は省略しています。標準配列の変更後は必ず「再起動」を選んでください。問題が見つかった場合は Issues へ報告してください。
