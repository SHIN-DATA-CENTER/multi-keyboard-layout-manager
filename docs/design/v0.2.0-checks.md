## 実装と設計

- `SetStandard` の core / engine / IPC v4 / helper / client / CLI / GUI の接続を確認。GUI は共通 VM を描画し、固定モード・準備中・blocker・no-op からの要求を止める。GUI の準備、follow、UAC 説明からの復帰、ExpectedPlan 付き要求の回帰テストを追加した。
- 標準配列の forward / revert は、同一起動で新しい保存値を現在の動作として表示しない。標準追従の行に再起動待ちと打鍵確認を出し、個別配列の行に誤って出さない。次の起動では再起動待ちを外すテストを追加した。
- 再起動確認は物理キーボード単位。不一致の collection を警告として優先し、未報告を全件成功にしない。GUID_NULL は物理 ID として共有しない。`SetStandard` の確認対象から配列維持の pin を除くテストを追加した。
- CLI の list/status、journal、操作の見出し、undo/revert の下見、回復の報告、GUI の履歴と undo/revert の下見へ起動依存の表示判定を接続。JSON は保存状態と表示状態を別に記録する。表示のためのジャーナル書き込みはない。
- RDP の配列の選択時期の断定を標準配列画面からも除いた。Microsoft の一次資料は `rdp-link.md` の各リンクを再確認した。通常 RDP キーから物理キーボードの打鍵成功を推測しない。
- README、インストール手順、回復手順を操作・再起動・取り消しの実装と照合した。リリース手順は `docs/maintainer/release-signing.ja.md` に従い、公開前条件の未達成中は版上げを行わない。
