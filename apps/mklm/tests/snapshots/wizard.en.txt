=== welcome
heading: Step 1 of 4: Welcome
body: MKLM tells Windows, keyboard by keyboard, whether it is a JIS or a US keyboard. This setup checks your input methods, lets you choose each keyboard's physical layout, and then makes the changes that are needed.
item: The settings apply to every user of this PC.
item: Each time a keyboard setting changes, Windows asks for administrator permission (MKLM is not code-signed yet, so the publisher shows as "Unknown").
item: MKLM records the values before its first change; "Back to before MKLM" puts them back later.
item: You can also finish without changing anything: choose "Set up later". The setup can be started again from Settings.
item: MKLM checks GitHub for a new version once a day (you can turn this off in Settings).
button: (Next)
can next: true

=== summary (fixed JIS, a new US keyboard: the migration)
heading: Step 4 of 4: Summary
body: These changes are made one after the other. Windows asks for administrator permission for each.
item: Switch to per-keyboard mode (the PC's standard layout JIS). One PC restart is needed.
item: Keychron Receiver to US (written with the switch)
warning: Do not choose "Use connected keyboard layout" in the Windows Settings app before this switch: chosen first, it makes the built-in keyboard US.
note: A US keyboard has no 半角/全角 key: turn Japanese input on and off with Alt+`.
note: The write order: first the built-in (PS/2) keyboards keep their layout in their own values, then the assignments, then the PC-wide values. If it stops halfway, the built-in keyboard's layout does not change; MKLM offers the recovery at its next start.
note: ⓘ This setting applies to every user of this PC.
standard: ◉ JIS (recommended: the current JIS)
standard: ○ US
migration: sign-in help
uac: Windows asks for permission next (the publisher shows as "Unknown"). Check that it names mklm-helper.exe, then choose Yes.

details: ACPI\FUJ0309\4&320DB4C2&0 OverrideKeyboardSubtype: 2 → 2

details: HID\VID_3434&PID_D027&MI_00&COL01\8&148AD7E3&0&0000 KeyboardSubtypeOverride: (none) → 0
